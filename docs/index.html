📋 Problem

3 APIs, 3 different JSON formats, missing fields, duplicates, silent schema changes. Revenue reports differ by 15%. CFO is asking questions nobody can answer.

💡 Solution

Medallion architecture (bronze → silver → gold) with 12 automated quality gates. Bronze = immutable raw replayable. Silver = validated + SCD2. Gold = star schema for BI.

🏗️ Architecture

API → Bronze (raw JSON) → Silver (validated, SCD2) → Gold (star schema)
                              ↓
                        12 Quality Gates

🔑 Key Decisions

Idempotent upserts: re-runs = identical results, zero duplicates.
SCD Type 2: customer history preserved.
Fail loudly: bad data blocks the load, never silently corrupts.
