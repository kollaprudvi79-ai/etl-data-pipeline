Batch ETL: REST API → bronze/silver/gold layers → star-schema warehouse, with data-quality gates and idempotent loads.

Flow

extract.py (paginated API, retries) → bronze/raw JSON
transform.py (validate, type, SCD2)     → silver/clean
pipeline.py (upserts, watermark)        → gold/star schema
quality.py (null/range/FK/freshness)    → fails loudly before publish

Run

python pipeline.py --since 2025-01-01 --until 2025-01-31
python pipeline.py --check-only   # quality gates only
